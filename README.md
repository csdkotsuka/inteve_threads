# Threads投稿アシスタント ｜ INTEVE × 理学療法教育DX

Threads（スレッズ）のアカウント（[@csdkotsuka](https://www.threads.net/@csdkotsuka)）運用を効率化・自動化するための、**スマホ特化型・投稿支援Webアプリ**です。  
理学療法士・養成校教員歴22年の経験に基づき厳選された**100本の高品質な投稿ストック**を収録。ワンタップで本文をコピーし、Threads投稿画面を直接起動して投稿できます。

---

## 🌟 主な機能

1. **ワンタップ・コピー & Threads直接投稿**
   - 投稿カードをタップするだけで、本文とハッシュタグが瞬時にクリップボードへコピーされます。
   - 「Threadsで投稿」ボタンを押すと、Threadsの投稿作成画面が直接立ち上がります。
2. **🎲 今日のランダム選出（ガチャ機能）**
   - 「今日の投稿をランダム選出！」ボタンを押すと、未投稿の中から1本を即座にポップアップ！
   - 今日つぶやくネタに迷った時でも、数秒で投稿を完了できます。
3. **🔀 シャッフル表示モード**
   - 100本の投稿順をランダムにシャッフルして一覧表示。毎日新鮮な気分で投稿を選べます。
4. **投稿進捗チェック（端末内自動保存）**
   - 「投稿済み」にチェックを入れると、進捗バー（例: `12 / 100 完了 (12%)`）が更新されます。
   - LocalStorageに保存されるため、ブラウザを閉じても記録が消えません。
5. **カテゴリー絞り込み & キーワード検索**
   - 5大ジャンル別の絞り込みや、「未投稿のみ」「完了済み」の切り替えが可能。
   - キーワード検索（「実習」「AI」「歩行」「国試」など）で目的の投稿を瞬時に抽出できます。
6. **固定ヘッダー & 外部連携**
   - スクロールしてもヘッダーが常時固定され、Threadsアカウント（`@csdkotsuka`）や [note](https://note.com/csdkazuhiro) へワンタップでアクセスできます。

## 🚀 使い方（GitHub PagesでWebアプリとして使う）

本リポジトリはHTML単体（1ファイル）で完全に動作するため、サーバー不要・完全無料でWebアプリとして公開できます。

1. 本リポジトリの **Settings**（設定）タブを開きます。
2. 左メニューの **Pages** を選択します。
3. **Build and deployment** の項目で、以下を選択して **Save** をクリックします：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/(root)`
4. 数分待つと、画面上部に公開URL（例: `https://<あなたのGitHubユーザー名>.github.io/inteve_threads/`）が表示されます。
5. そのURLをスマホのブラウザ（Safari や Chrome）で開けば、すぐに使えます！

## 📱 スマホのホーム画面に追加してアプリ化する（超おすすめ！）

Safari（iPhone）や Chrome（Android）のホーム画面追加機能を使うと、本物のスマホアプリのようにワンタップで起動できるようになります。

- **iPhone（Safari）の場合**：
  1. 公開URLをSafariで開く
  2. 画面下部の共有ボタン（四角から上矢印が出ているアイコン）をタップ
  3. **「ホーム画面に追加」** を選択
- **Android（Chrome）の場合**：
  1. 公開URLをChromeで開く
  2. 右上のメニュー（︙）をタップ
  3. **「ホーム画面に追加」** または **「アプリをインストール」** を選択
