# Threads 運用ダッシュボード ｜ INTEVE × 理学療法教育DX

Threads（スレッズ）のアカウント（[@csdkotsuka](https://www.threads.net/@csdkotsuka)）運用を効率化・完全自動化するための、**クラウド同期 ＆ 予約自動投稿Webアプリ**です。  
理学療法士・養成校教員歴22年の経験に基づき厳選された**100本の高品質な投稿ストック**を収録。端末間リアルタイム同期、オンライン推敲・編集、日時予約、Threads公式APIによる自動投稿、閲覧数・いいね等のインサイト分析までを一元管理できます。

---

## 🌟 主な機能

1. **☁️ Firebase（Firestore）マルチデバイス・リアルタイム同期**
   - PCやスマホ、どの端末で操作しても、投稿チェック状態・本文編集・予約日時が瞬時に同期されます。
2. **✏️ オンライン推敲・テキスト微調整**
   - 各投稿の「✏️ 編集・予約」から、本文やハッシュタグをアプリ上で直接編集・保存できます。文字数カウンター付き。
3. **📅 投稿日時の予約設定**
   - カレンダーと時刻ピッカーで投稿日時を設定可能。投稿直前まで何度でも日時の変更・解除ができます。
4. **🤖 Threads 公式API連携 ＆ 完全自動投稿**
   - 指定時刻が到来すると、バックグラウンドワーカー（`auto_poster.py` または GitHub Actions）が Threads へ自動投稿！
   - 投稿完了後、ステータスは自動で「✅ 投稿済み」に更新されます。
5. **📊 インサイト分析（閲覧数・いいね数・返信数・リポスト数）**
   - 投稿済みの投稿について、Threads APIからインサイトを自動取得。
   - 「👁️ 閲覧数」「❤️ いいね」「💬 返信」「🔁 再投稿」が各カードにリアルタイム表示されます。
6. **🎲 ランダム選出 & カテゴリー絞り込み**
   - 「未投稿ストック」「予約中」「投稿済み」のステータスタブ切り替えや、5大ジャンル別の絞り込み、キーワード全文検索に対応。

## 🚀 使い方（GitHub PagesでWebアプリとして使う）

本リポジトリはHTML単体（1ファイル）で完全に動作するため、サーバー不要・完全無料でWebアプリとして公開できます。

1. 本リポジトリの **Settings**（設定）タブを開きます。
2. 左メニューの **Pages** を選択します。
3. **Build and deployment** の項目で、以下を選択して **Save** をクリックします：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/(root)`
4. 数分待つと、画面上部に公開URL（例: `https://<あなたのGitHubユーザー名>.github.io/inteve_threads/`）が表示されます。
5. そのURLをスマホのブラウザ（Safari や Chrome）で開けば、すぐに使えます！

## 📱 スマホのホーム画面に追加してアプリ化する（超おすすめ！）

Safari（iPhone）や Chrome（Android）のホーム画面追加機能を使うと、本物のスマホアプリのようにワンタップで起動できるようになります。

- **iPhone（Safari）の場合**：
  1. 公開URLをSafariで開く
  2. 画面下部の共有ボタン（四角から上矢印が出ているアイコン）をタップ
  3. **「ホーム画面に追加」** を選択
- **Android（Chrome）の場合**：
  1. 公開URLをChromeで開く
  2. 右上のメニュー（︙）をタップ
  3. **「ホーム画面に追加」** または **「アプリをインストール」** を選択
